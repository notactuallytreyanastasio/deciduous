Exploring What You Built

With 56 nodes and 66 edges, snowflex's decision graph tells the complete story of how the library evolved. Let's explore it.

The Web Viewer

The fastest way to browse a decision graph is the built-in web viewer. One command starts it:

Starting the web viewer
deciduous serve Serving at http://localhost:3000 (auto-refreshes every 30s)

The viewer provides four ways to look at your graph:

View What It Shows Best For
DAG Directed graph with nodes and edges rendered spatially Understanding the full structure and connections
Timeline Nodes arranged chronologically by creation date Seeing the order in which decisions were made
Chains Connected components grouped together Following a single line of reasoning end to end
Archaeology Narrative stacks showing evolution and pivots Understanding how and why approaches changed over time

Click any node in the viewer to see its details: type, status, confidence, connected edges, rationales, commit links, and any attached documents.

Leave it running

The web viewer auto-refreshes every 30 seconds. Leave it running in a background tab while you work—your graph stays current as Claude adds nodes and edges during a session.

Pulse — Graph Health Report

The deciduous pulse command gives a quick summary of your graph's health and structure:

deciduous pulse
deciduous pulse Graph Pulse ──────────────────────────────────────────────────────────── Nodes: 56 total goal: 3 option: 8 decision: 7 action: 12 outcome: 10 observation: 12 revisit: 2 Edges: 66 total leads_to: 52 chosen: 8 rejected: 6 Statuses: active: 18 completed: 14 superseded: 12 rejected: 6 pending: 4 abandoned: 2 Branches: main: 56 nodes Orphan nodes: 0 Dangling outcomes: 0 Last activity: 2021-03-15T10:45:00

Pulse is useful for catching problems: orphan nodes (nodes with no connections), dangling outcomes (outcomes not linked to an action), and overall balance of node types.

DOT Visualizations

For documentation and PRs, export subsets of the graph as DOT format (or directly to PNG if you have Graphviz installed):

DOT export
deciduous dot --nodes 33-40 --title "ODBC to HTTP Pivot" --png Wrote docs/decision-graph.dot Wrote docs/decision-graph.png (8 nodes, 7 edges)

This generates a visual graph of just the pivot—from the observation that ODBC was failing, through the revisit, to the new HTTP implementation and its outcome.

Useful flags for deciduous dot:

Flag What It Does Example
--nodes Select specific nodes by ID range --nodes 33-40 or --nodes 1,3,5-10
--roots Start from a root node and BFS outward --roots 1 (follow all children of goal #1)
--title Set a graph title --title "ODBC to HTTP Pivot"
--rankdir Graph direction --rankdir LR for left-to-right layout
--png Generate PNG image (requires Graphviz) --png
--auto Branch-specific filenames (prevents merge conflicts) --auto outputs decision-graph-main.png

Without --png, the command outputs a DOT file that you can render with any Graphviz-compatible tool. With --png, it calls dot directly and gives you the image.
