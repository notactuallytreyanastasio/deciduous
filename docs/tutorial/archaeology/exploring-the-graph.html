Exploring What You Built

The graph is for asking questions. Claude asks it through MCP; you ask it through nodes, show, edges and pulse, or in a browser.

Asking Claude

here ─[leads_to]→ #8: found in production
here ─[leads_to]→ #9: ODBC too fragile for production
Claude
Outcome #6, the ODBC wrapper, collected three observations: sessions expiring after four hours idle (#7), UTF-16 corrupting results (#8), and the summary that also names Apple Silicon and memory (#9). #9 forced revisit #10, which led to decision #11: switch to Snowflake's HTTP REST API with JWT auth. Of the two options under #11, the transport behaviour with Req (#12) was chosen because it leaves room for other transports; a direct client (#13) was rejected as too rigid. The rewrite (#14) produced v1.0 (#15).

In a session connected to the server Claude does this with ask_graph (ranked search across the workspace, or across every workspace on the server) and show_node, get_ancestors and get_descendants. On the local deciduous mcp server the tools are search_nodes and trace_chain. The reasoning is the same: find the revisit, walk its edges.

nodes filters by -t/--node-type, -b/--branch and --theme. It does not filter by status; deciduous nodes --status active is error: unexpected argument '--status' found, and so is --type (the long form is --node-type). show --json prints the row as JSON, with the metadata as a JSON string inside it. Any command that takes a node accepts its integer id, a prefix of its change id (the CHANGE column), or a server id.

Pulse

$ deciduous pulse --summary
=== PULSE ===

Summary:
  Nodes: 15 | Edges: 15
  Types:  goal(1) option(4) decision(2) action(2) outcome(2) observation(3) revisit(1)
  Status: pending(14) superseded(1)
  Confidence: high(9) medium(1) low(1) unset(4)

Without --summary, pulse also lists active goals with everything under them, recent activity, and, when there are any, orphan nodes:

Orphan Nodes (1):
  #30 [option] "Separate worklfow files (duplicate)" - no connections

A root goal is the only node that should have no incoming edge; anything else in that list is a connection somebody forgot. pulse --json gives the same report as data, and -b restricts it to one branch.

The Web Viewer

$ deciduous serve
🌳 Deciduous
   Graph viewer: http://localhost:3000
   Press Ctrl+C to stop

Six views: DAG, Chains, Timeline, Graph, Roadmap and Story, with branch filtering, search and a detail panel. It reads the local database, so with a server configured run deciduous remote pull first if other machines have been writing. -p changes the port. The viewer does not yet show the evidence kind or file hashes that the transcript import adds to nodes; show does.
