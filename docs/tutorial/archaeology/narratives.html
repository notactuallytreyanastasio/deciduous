Snowflex began in June 2019 as a wrapper around Erlang's ODBC driver (#1 to #6), the only route from Elixir to Snowflake at the time; an HTTP client (#3) was considered and dropped because Snowflake had no public SQL API. In production the ODBC transport accumulated faults: sessions expiring after four hours idle (#7), UTF-16 corrupting results (#8), then Apple Silicon and memory (#9).

The pivot (#10) led to decision #11: Snowflake's HTTP REST API with JWT auth. A transport behaviour with an HTTP implementation on Req (#12) was chosen over a direct client (#13) because it leaves room for other transports. The v1.0 rewrite (#14, commit 910ac13) shipped as #15 with no native dependencies.

Written to .deciduous/narratives.md.

narratives.md lives in .deciduous/, which init's ignore rule covers; copy it out or change the rule if the story should travel with the code. narratives init --force overwrites; -o writes elsewhere.

Each chain is old approach, the observation that undid it, the revisit, the new decision. --json for data, -b for one branch.

The Timeline

$ deciduous archaeology timeline --limit 8
=== TIMELINE === (8 nodes)

  2020-06-10  #8   [observation]   Snowflake returns UTF-16 that corrupts query results pending
  2021-03-01  #12  [option]        Transport behaviour with an HTTP implementation using Req pending       90%
  2021-03-01  #13  [option]        Direct HTTP client, no transport abstraction pending       60%
  2021-04-01  #14  [action]        Complete v1.0 rewrite: HTTP REST API, JWT auth, Transport behaviour pending       95%
  2021-04-15  #15  [outcome]       Snowflex v1.0: HTTP-based Snowflake adapter, no native dependencies pending       95%
  2026-10-24  #9   [observation]   ODBC limitations accumulating: auth expiry, UTF-16 corruption, Apple Silicon, memory pending
  2026-10-24  #10  [revisit]       Reconsidering: Working single-connection ODBC wrapper pending
  2026-10-24  #11  [decision]      Switch to Snowflake's HTTP REST API with JWT auth pending       90%

--limit shows the most recent N (0, the default, is all); -t filters by type. The three 2026 rows are the pivot nodes from the previous page, which archaeology pivot dated to the day it ran. That is the one wrinkle in an otherwise backdated graph, and the timeline is where you see it.

Two audiences

The graph is for precision: an id, an edge, a commit. The narrative is for a person who needs the shape of the story in two paragraphs. Keep the ids in the prose so the reader can get from one to the other.
