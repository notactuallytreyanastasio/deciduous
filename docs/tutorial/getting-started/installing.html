Installing Deciduous

Three ways to install, zero runtime dependencies.

Deciduous is distributed as a single static binary. Pick whichever installation method works best for your setup.

Option 1: Homebrew (macOS / Linux)

The fastest path if you already have Homebrew installed:

Homebrew
brew install notactuallytreyanastasio/tap/deciduous

This installs the latest release and makes the deciduous command available globally. Homebrew will handle updates when you run brew upgrade.

Option 2: Cargo (Rust Toolchain)

If you have the Rust toolchain installed:

Cargo
cargo install deciduous

This compiles from source and places the binary in your Cargo bin directory (usually ~/.cargo/bin/). Compilation takes a couple of minutes on most machines.

Option 3: Pre-built Binaries

Download a pre-built binary directly from the GitHub Releases page. Binaries are available for every major platform:

Platform Architecture Binary Name
macOS Apple Silicon (M1/M2/M3/M4) deciduous-darwin-arm64
macOS Intel deciduous-darwin-amd64
Linux x86_64 deciduous-linux-amd64
Linux ARM64 deciduous-linux-arm64
Windows x86_64 deciduous-windows-amd64.exe

After downloading, make the binary executable and move it somewhere on your PATH:

Manual Install
chmod +x deciduous-darwin-arm64 mv deciduous-darwin-arm64 /usr/local/bin/deciduous

Verify the Installation

Regardless of which method you chose, confirm that deciduous is available:

Verify
deciduous --version deciduous 0.13.2

If you see a version number, you are good to go.

Optional: Graphviz for PNG Export

Deciduous can export decision graphs as DOT files natively. If you also want to generate PNG images directly (for embedding in PRs or documentation), you will need Graphviz installed:

Graphviz (Optional)
# macOS brew install graphviz # Ubuntu / Debian sudo apt install graphviz # Fedora sudo dnf install graphviz

Without Graphviz, the deciduous dot --png flag will not work, but everything else functions normally. You can always install it later when you need PNG output.

Zero runtime dependencies

Deciduous is a single static binary with SQLite compiled in. There is no database server to install, no runtime to configure, and no background process to manage. The binary is entirely self-contained for all core features.
