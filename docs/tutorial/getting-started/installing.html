Installing Deciduous

The CLI is one static binary. The graph it writes to lives in PostgreSQL, so the one thing to have ready is a PostgreSQL on localhost:5432.

Homebrew (macOS or Linux)

Homebrew
brew tap notactuallytreyanastasio/tap brew install deciduous

Later upgrades are brew upgrade deciduous, followed by deciduous update in each project (deciduous update --all ~/code for all of them at once).

Cargo, or from Source

Cargo
cargo install deciduous --locked # or build the repository; rust-toolchain.toml pins Rust 1.92.0 git clone https://github.com/notactuallytreyanastasio/deciduous.git cd deciduous && cargo build --release

The binary lands in ~/.cargo/bin/ (or target/release/ from source). The toolchain is pinned because stable Rust moved in October 2026 and clippy 1.99 started reporting lints inside a derive the crate uses; the pin keeps a tree that did not change building the same way.

Manual install
curl -LO https://github.com/notactuallytreyanastasio/deciduous/releases/latest/download/deciduous-darwin-arm64 chmod +x deciduous-darwin-arm64 sudo mv deciduous-darwin-arm64 /usr/local/bin/deciduous

Verify

Verify
deciduous --version deciduous 1.1.0 which -a deciduous

which -a matters if you have installed more than one way: the first on PATH is the one that runs, and deciduous update compares projects against that one's version.

PostgreSQL

The graph every project writes to lives in a server backed by PostgreSQL. By default deciduous init installs that server on this machine as a background service against the PostgreSQL on localhost:5432, connecting as your OS user. If nothing answers there, init says so in its menu and tells you how to get one:

A PostgreSQL for the default choice
# macOS brew install postgresql@17 && brew services start postgresql@17 # Debian / Ubuntu sudo apt install postgresql

You can instead name any other PostgreSQL by URL, let Docker run a new one for you, or point at a server someone else runs. All four are offered on the next page. Nothing else is installed by hand: the server executable (one file with Erlang and Elixir inside) is downloaded for the CLI's own version and verified against the release's checksums.

Optional: Graphviz

deciduous dot writes DOT without any dependency. deciduous dot --png runs Graphviz's dot to make the image that goes in a pull request:

Graphviz (optional)
# macOS brew install graphviz # Ubuntu / Debian sudo apt install graphviz
