The Deciduous Tutorial

One project, start to finish: reconstruct two years of a library's decisions from its git log, then add a chapter by working a real issue with an AI assistant that logs as it goes. Written for deciduous 1.1.0.

The project is snowflex, an Elixir library for querying Snowflake. It began as an ODBC wrapper, grew a connection pool, and was rewritten on Snowflake's HTTP API. Every command in this tutorial was run against 1.1.0 in a scratch copy of that story on 2026-10-24, and the output shown is what the binary printed.

Where the examples come from

A scratch git repository with three commits standing in for snowflex's history, DECIDUOUS_NO_SERVER=1 so init skipped the server step, and the 1.1.0 release binary. Node ids in the examples (1 to 29) are the ids that run produced. Your ids will differ; nothing else should.
