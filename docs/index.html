A codebase you inherited has no graph. /decision-graph writes one from what the repository already says: the goals, the options, what was chosen, and every point where a choice was reconsidered. Then the question has an answer with a commit on it.

Read what the command does

What it does not do
infers
It only knows what the history records. A commit that says what changed but not why leaves a guess in the graph; each node carries its commit so you can check.
misses
Reasoning that lived in a meeting or a chat never reached the repository, so it never reaches the graph.
costs
It reads the whole log and the PR threads. On a large repository, scope it to a path or a date range.

Looking is the point.

The collaboration started before the first line of code. Every agent inherited the same repository rules: read, borrow, improve, and leave credit.

# Tetris Arena
Ten agents, one repo, one shared decision graph.
Each of you builds a playable Tetris from nothing,
in your own worktree, on your own branch.

Looking is not cheating here. It is the point.
Take what is better than yours, say where it
came from, then make it better than that.

## Peeking: do it, on a schedule
After every milestone, and before any real
design decision:
1. check_activity: who is writing, on which branch.
2. query_nodes: decisions, no branch filter.
3. Read the code in the sibling worktrees.

When you take something, log an observation:
“Took X from agent-M because Y; changed Z.”
Link it to the action. Say it in the commit.

What was actually in each agent’s environment?
worktree
Its own checkout and branch. Locks are per branch, so sessions do not interleave writes on the same branch.
MCP
Shared graph tools inside the session: add_node, add_edge, query_nodes, check_activity. Each call carried workspace: “tetris-arena” and branch: “agent-N”.
../agent-M
Every sibling worktree was readable. Agents could inspect each other’s code before and after commits.
opening prompt
“You are agent 7 of 10 in the tetris arena. This directory is your worktree, on branch agent-7. Read CLAUDE.md here and follow it exactly. Begin.”
permissions
The experiment ran with permission prompts off. This describes the run, not a prerequisite for using Deciduous.
