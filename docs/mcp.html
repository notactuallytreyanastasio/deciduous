MCP Server

Give Claude direct access to your decision graph. 31 tools for searching, tracing, and analyzing decisions. Works with Claude Code, Desktop, and cowork.

Quick Start: Cowork

Each cowork agent gets its own decision tree. One config change:

.claude/settings.local.json

{
  "mcpServers": {
    "deciduous": {
      "command": "deciduous",
      "args": ["mcp"]
    }
  }
}

Each agent's MCP server auto-resumes sessions across restarts. Nodes auto-associate with the active conversation.

Quick Start: Claude Desktop

~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "deciduous": {
      "command": "deciduous",
      "args": ["mcp"],
      "cwd": "/path/to/your/project"
    }
  }
}

Set cwd to your project root (where .deciduous/ lives). Restart Claude Desktop.
